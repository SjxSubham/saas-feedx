# Contributing to saas-feedx

Thank you for your interest in contributing to **saas-feedx**!

## How to Contribute

1. **Open an Issue First**
   - If you want to work on something, please start by [raising an issue](https://github.com/SjxSubham/saas-feedx/issues).
   - Clearly describe what you want to work on or improve.
   - If your issue is valid and approved, you are welcome to start contributing!

2. **Valid Contributions Only**
   - Contributions should add meaningful value to the project.
   - **Pull requests that only include documentation changes, spammy comments, or trivial edits (such as adding unnecessary lines or whitespace) will not be accepted.**
   - Please ensure your code is clean, well-documented, and follows the project’s style.

3. **Star the Repository**
   - If you contribute, please consider starring the repository to show your support!

## Pull Request Guidelines

- Reference the issue you’re working on in your pull request.
- Provide a clear description of the changes you are making.
- Make sure your PR passes all checks and tests.

## Code of Conduct

Be respectful and considerate. Any form of spam or disruptive behavior will not be tolerated.

Thank you for helping make **saas-feedx** better
